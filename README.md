# Rick and Morty theme for Eitr

A dark [Eitr](https://eitr.info) theme with Rick and Morty art: portal green on dark space, with 9 wallpapers.

![Preview](rick-and-morty/preview.png)

## Install

Open the Eitr Store, choose Themes, and search for Rick and Morty.
